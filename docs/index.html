Why "I deleted it" isn't enough

History is forever

Deleting a line only adds a new commit. The old commit still has the secret, and git show <sha> brings it back for anyone with a clone.

Pushed means public

Once a commit reaches a remote, forks, CI caches and mirrors may keep a copy. Bots scan public pushes within minutes.

Rotate first, rewrite second

Revoking the credential is the real fix. Rewriting history with git filter-repo just keeps the old value from spreading further.
